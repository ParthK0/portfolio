# Developer Portfolio

A responsive, high-performance, and aesthetic developer portfolio website built using vanilla technologies (HTML5, CSS3, and JavaScript).

## Features

- **Modern Dark Aesthetic**: Clean layout with sleek glassmorphism and subtle glowing accents.
- **Responsive Layout**: Adapts to mobile, tablet, and desktop screens.
- **Dynamic Projects Filter**: Categorized display of projects with interactive filters.
- **Smooth Animations**: Transitions, hover effects, and a dynamic typing animation in the hero section.
- **Interactive Contact Form**: Client-side validation and feedback.

## Tech Stack

- **Structure**: HTML5
- **Styling**: CSS3 (Vanilla)
- **Interactions**: Vanilla JavaScript

## Getting Started

### Prerequisites

You only need a modern web browser to view this project locally.

### Local Development

1. Clone this repository:
   ```bash
   git clone https://github.com/ParthK0/portfolio.git
   ```
2. Open `index.html` in your favorite web browser, or serve it using a local development server (e.g., Live Server in VS Code).
