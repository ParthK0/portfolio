# Developer Portfolio

A modern, scroll-based developer portfolio built with Three.js, Vite, and GSAP.

## Tech Stack
- **Frontend:** HTML, Vanilla CSS, JavaScript
- **3D & Animation:** Three.js, GSAP
- **Build Tool:** Vite


## Features
- Single-canvas Three.js architecture with scissor-test rendering
- Dynamic LeetCode stats integration via external API
- Smooth scroll reveals and scroll-spy navigation
